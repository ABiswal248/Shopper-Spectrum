Shopper Spectrum: Customer Segmentation and Product Recommendation System
Overview

Shopper Spectrum is an E-Commerce Analytics project that analyzes customer purchase behavior and provides personalized product recommendations. The project uses RFM Analysis, K-Means Clustering, and Collaborative Filtering techniques.

Problem Statement

The e-commerce industry generates huge amounts of transaction data every day. Understanding customer behavior helps businesses improve customer retention and increase sales through personalized recommendations.
